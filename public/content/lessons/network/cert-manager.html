Cert Manager#

cert-manager 在 Kubernetes 集群中添加证书和证书颁发者作为资源类型，并简化了获取、续订和使用这些证书的过程。

部署#

helmwave up --build

修改 issuer/clusterissuer.yaml 中的 email 为自己的邮箱地址, 然后部署证书签发

kubectl apply -k issuer/

测试#

修改 tests/ingress.yaml 中的 hosts 和 host 为实际 DNS 域名

# 部署
kubectl apply -k tests

# 访问 https://kuard.play.example.com

# 卸载
kubectl delete -k tests

可以通过查看签名过程

kubectl get ing
kubectl get cert
kubectl get challenges

卸载#

kubectl delete -k issuer/

helmwave down
