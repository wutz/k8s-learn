Network Operator 部署指南#

NVIDIA Network Operator 用于配置 Kubernetes 集群中的 NVIDIA 网络（Mellanox）设备，支持 RDMA、GPUDirect RDMA、SR-IOV 等功能。

依赖#

  • 安装 nfd
  • 下载并安装 DOCA OFED (MLNX OFED 已迁移到 DOCA OFED)

部署#

helmwave up --build

# 查看部署状态
helm ls

配置#

kubectl apply -f nicclusterpolicy.yaml

使用 RoCE 网络需要一些网络隔离时， 则需要使用 MacVLAN

使用与测试#

  • 网络为 IB 时，申请资源必须设置 pod.containers.resources.limits.rdma/hca: 1
  • 网络为 RoCE 时，除了像 IB 一样申请 RDMA 设备外，还需要使用 host ip 必须设置 pod.spec.hostNetwork: true
# 部署测试 pod
kubectl apply -f tests.yaml

# 进入 server 测试 pod
kubectl exec -it tests-rdma-hca-xxx -- /bin/bash
# 查询 ip 作为 server ip, bond0 需要替换实际可以互通网卡名称
> ip addr show bond0
# 查询 gid 和 mlx 设备名称
> show_gids |grep v2
# 启动测试, 作为 server, -x 指定 gid，-d 指定 mlx 设备名称
> ib_send_bw -x 3 -d mlx5_bond_0

# 进入 client 测试 pod
kubectl exec -it tests-rdma-hca-yyy -- /bin/bash
# 查询 gid 和 mlx 设备名称
> show_gids |grep v2
# 启动测试, 作为 client，-x 指定 gid，-d 指定 mlx 设备名称
> ib_send_bw -x 3 -d mlx5_bond_0 <server_ip>

# 删除测试 pod
kubectl delete -f tests.yaml

卸载#

kubectl delete -f nicclusterpolicy.yaml

helmwave down
