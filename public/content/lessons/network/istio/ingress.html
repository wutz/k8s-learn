Kubernetes Ingress#

⚠️ 注意: 这是基于 Kubernetes Ingress API 的旧方案。推荐新服务使用 ../gateway-api/ 部署配置。

  • Gateway API 是 Kubernetes 官方推荐的下一代流量管理 API
  • 功能更强大：支持流量分割、Headers 操作、跨命名空间路由等
  • POC 验证结论：Gateway API 可完全替代 Ingress API

本目录保留用于过渡期参考，后续可能废弃。

与 Gateway API 的关系#

维度 本目录 (Ingress) gateway-api/
API 标准 Kubernetes Ingress API (旧) Gateway API (新标准)
推荐程度 ⚠️ 过渡期保留 ✅ 推荐使用
功能范围 基础路由 高级路由、流量分割等
维护状态 维持现状 持续优化

部署#

如果需要设置 istio 作为缺省 IngressClass, 则解开 ingress-class.yaml 中的注释

helmwave up --build

测试#

# 部署测试 Ingress
kubectl apply -f tests.yaml

# 获取 Ingress 地址
INGRESS_HOST=$(kubectl get svc -n istio-system istio-ingressgateway -o jsonpath='{.status.loadBalancer.ingress[0].ip}')
INGRESS_PORT=$(kubectl get svc -n istio-system istio-ingressgateway -o jsonpath='{.spec.ports[?(@.name=="http2")].port}')

# 测试 Ingress
curl -s -I -HHost:httpbin.example.com "http://$INGRESS_HOST:$INGRESS_PORT/status/200"

卸载#

helmwave down
