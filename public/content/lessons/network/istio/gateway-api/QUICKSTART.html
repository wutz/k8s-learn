Gateway API 快速开始#

1. 部署 Gateway#

cd /Users/wh/data/worklib/src/github.com/kitsnail/mc01-deploy/network/istio/gateway-api
kubectl apply -k .

2. 验证 Gateway 状态#

kubectl get gateway -n istio-system main-gateway

3. 为命名空间添加标签#

kubectl label namespace my-namespace gateway-access=main-gateway

4. 创建 HTTPRoute#

创建 my-app-httproute.yaml:

apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: my-app
  namespace: my-namespace
spec:
  parentRefs:
  - name: main-gateway
    namespace: istio-system
  hostnames:
  - "my-app.example.com"
  rules:
  - matches:
    - path:
        type: PathPrefix
        value: /
    backendRefs:
    - name: my-app
      port: 80

应用配置:

kubectl apply -f my-app-httproute.yaml

5. 测试访问#

# 获取 Gateway 地址
GATEWAY_HOST=$(kubectl get gateway -n istio-system main-gateway -o jsonpath='{.status.addresses[0].value}')

# 测试访问
curl -HHost:my-app.example.com "http://$GATEWAY_HOST"

常用配置示例#

路径重写#

rules:
- matches:
  - path:
      type: PathPrefix
      value: /api/v1
  filters:
  - type: URLRewrite
    urlRewrite:
      path:
        type: ReplacePrefixMatch
        replacePrefixMatch: /

Headers 操作#

filters:
- type: RequestHeaderModifier
  requestHeaderModifier:
    add:
    - name: X-Custom-Header
      value: "my-value"
- type: ResponseHeaderModifier
  responseHeaderModifier:
    add:
    - name: X-Response-Header
      value: "from-gateway"

流量分割#

rules:
- backendRefs:
  - name: my-app-v1
    port: 80
    weight: 90
  - name: my-app-v2
    port: 80
    weight: 10

超时控制#

rules:
- timeouts:
    request: 30s
    backendRequest: 10s
  backendRefs:
  - name: my-app
    port: 80
