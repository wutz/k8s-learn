KGateway#

概述#

KGateway 是一个面向 Kubernetes 的云原生 API 网关，提供高级流量管理、路由和推理功能。此技能部署 KGateway，支持 Gateway API 标准和 AI 推理扩展。

功能特性#

  • Gateway API 支持：完全符合 Kubernetes Gateway API 标准
  • 推理扩展：通过 Gateway API Inference Extension 为 AI/ML 推理工作负载提供专业支持
  • Agent 网关：内置 AI 代理路由和管理支持

部署#

helmwave up --build

验证#

测试功能#

# 创建测试 Gateway
cat <<EOF | kubectl apply -f -
apiVersion: gateway.networking.k8s.io/v1beta1
kind: Gateway
metadata:
  name: test-gateway
  namespace: kgateway-system
spec:
  gatewayClassName: kgateway
  listeners:
  - name: http
    protocol: HTTP
    port: 80
EOF

# 验证 Gateway 创建
kubectl get gateway -n kgateway-system test-gateway

卸载#

# 移除 KGateway 和所有组件
helmwave down
