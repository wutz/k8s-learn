准备#

管理工具 pdsh#

  • 为了安全性，后续所有 ssh 访问均从本地发起
# Ubuntu
apt install pdsh -y
# macOS
brew install pdsh
# Rocky/RHEL
yum install -y epel-release
yum install -y pdsh pdsh-rcmd-ssh

# 生成 hosts 用于后续执行 pdsh / pdcp
cat << 'EOF' > all
bj1mn[01-03]
bj1gn[001-003]
EOF

# 设置 pdsh 使用 ssh 而非缺省的 rsh
cat << 'EOF' > /etc/profile.d/pdsh.sh
export PDSH_RCMD_TYPE=ssh
export PDSH_REMOTE_PDCP_PATH=pdcp
EOF
source /etc/profile.d/pdsh.sh

# 所有节点安装 pdsh
pdsh -w ^all apt install -y pdsh

设置 ssh 无密码登录#

为了安全性，后续关闭所有节点密码登录

# 如果本地没有 ssh 密钥，则生成
ssh-keygen -t ecdsa

# ssh-copy 设置无密码登录所有节点
pdsh -w ^all -R exec ssh-copy-id %h

网络#

设置节点统一 interface 名称#

  • CNI 依赖一致的 interface 名称
  • 如果 interface 名称已统一，可以跳过
  • 一般物理机上 interface 名称需要根据实际情况进行修改统一名称，下面是一个示例
cat << 'EOF' /etc/netplan/00-installer-config.yaml
network:
  ethernets:
    eth0:
      addresses:
      - 10.128.0.1/16
      routes:
      - to: default
        via: 10.128.255.254
      nameservers:
        addresses:
        - 119.29.29.29
        - 223.5.5.5
        - 223.6.6.6
      match:
        macaddress: fa:16:3e:f1:c3:fd
      set-name: eth0
EOF

netplan apply
# 检查网络配置
pdsh -w ^all ip r
# 检查 dns 配置
pdsh -w ^all resolvectl dns

检查所有节点 MTU 是否一致并且正确#

# eth0 替换为实际的 interface 名称
pdsh -w ^all ip link show eth0 | grep mtu

输出结果应该为 mtu 1500

更新内核#

# Ubuntu 20.04/22.04
pdsh -w ^all apt update
pdsh -w ^all apt upgrade -y
reboot
pdsh -w ^all uname -r

确保所有节点使用一致的内核版本后，再进行锁定
cat << 'EOF' > nolinuxupgrades
Package: linux-*
Pin: version *
Pin-Priority: -1
EOF
pdcp -w ^all nolinuxupgrades /etc/apt/preferences.d/nolinuxupgrades
# Rocky/RHEL 8/9
yum install -y kernel
reboot
uname -r

禁止软件包自动更新#

# Ubuntu 22.04/24.04
pdsh -w ^all systemctl stop unattended-upgrades
pdsh -w ^all systemctl disable unattended-upgrades
pdsh -w ^all systemctl mask unattended-upgrades

# 配置关闭自动更新
pdsh -w ^all "sed -i 's/1/0/' /etc/apt/apt.conf.d/20auto-upgrades"

# 配置自动安全更新
cat << 'EOF' > overwrite.conf
[Timer]
Persistent=false
EOF
pdsh -w ^all mkdir -p /etc/systemd/system/apt-daily.timer.d/
pdcp -w ^all overwrite.conf /etc/systemd/system/apt-daily.timer.d/
pdsh -w ^all mkdir -p /etc/systemd/system/apt-daily-upgrade.timer.d/
pdcp -w ^all overwrite.conf /etc/systemd/system/apt-daily-upgrade.timer.d/

性能#

关闭 swap#

pdsh -w ^all swapoff -a
pdsh -w ^all cp /etc/fstab /etc/fstab.bak
pdsh -w ^all "sed -i 's/.*swap.*/#&/' /etc/fstab"

检查是否开启 CPU 超线程#

pdsh -w ^all 'lscpu | grep "Thread(s) per core"'

输出结果必须为 Thread(s) per core: 2

BIOS 中控制：Processor Configuration -> Hyper-Threading / Enable LP [Global] : Enabled

开启 CPU Performance Mode#

如果节点间 ping 延迟大于 0.05ms， 则需要关闭 CPU 省电模式开启 Performance 模式

# Ubuntu 额外需要执行 
apt install -y tuned
systemctl enable tuned --now

# 设置 latency-performance 模式
tuned-adm profile latency-performance
# 查看支持配置和当前激活模式
tuned-adm list
# 只查看当前激活模式
tuned-adm active

# 如果需要改回省电模式，则修改为 balanced
tuned-adm profile balanced

BIOS 控制：Processor Configuration -> Power Management:

  • P States -> SpeedStep: Disabled
  • C States -> C1E : Disabled
  • C States -> Enable Monitor MWAIT: Disabled

关闭 IOMMU#

BIOS 控制：IIO Configuration -> Intel VT for Directed I/O: Disabled

安全#

关闭 SELinux 或 AppArmor#

  • RHEL/Rocky 等系统
vi /etc/selinux/config
# 将 SELINUX=enforcing 修改为 SELINUX=disabled
SELINUX=disabled

# 重启
reboot
# 查看状态
getenforce
  • Ubuntu 系统
vi /etc/default/grub
# 在 GRUB_CMDLINE_LINUX 中追加 apparmor=0
GRUB_CMDLINE_LINUX="apparmor=0"

# 更新 grub
update-grub
# 重启
reboot
# 查看状态
aa-enabled

存储节点#

考虑到存储节点需要对外提供服务，需要禁止计算节点访问存储节点 22 端口.

所有存储节点需要执行下面步骤, 假如：

  • 存储节点在网段：100.68.16.0/20
  • 外部 VPN 所在 IP：100.68.3.100
# 缺省允许进入和出去
ufw reset
ufw default allow incoming
ufw default allow outgoing
ufw enable

# 查看
ufw status verbose

# 允许特定网络和 IP 访问 22 端口
ufw allow from 100.68.16.0/20 to any port 22
ufw allow from 100.68.3.100 to any port 22
# 禁止所有其他来源访问 22 端口
ufw deny 22

# 查看
ufw status verbose

RockyLinux8 系统可以使用等效的iptables规则进行配置

# 安装iptables服务
dnf -y install iptables-services

# 缺省允许进入和出去
iptables -F
iptables -X
iptables -P INPUT ACCEPT
iptables -P OUTPUT ACCEPT
iptables -P FORWARD ACCEPT

# 允许特定网络和IP访问22端口
iptables -A INPUT -p tcp -s 100.68.16.0/20 --dport 22 -j ACCEPT
iptables -A INPUT -p tcp -s 100.68.3.100 --dport 22 -j ACCEPT
iptables -A INPUT -p tcp --dport 22 -j DROP

# 查看
iptables -L

# 持久化
iptables-save >/etc/sysconfig/iptables

# 开机自动生效规则
systemctl enable iptables
