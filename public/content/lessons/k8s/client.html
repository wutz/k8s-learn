使用常用客户端工具#

kubectl#

阅读文章 https://kubernetes.io/zh-cn/docs/reference/kubectl/

常用技巧：

  • 设置常用环境变量
cat << 'EOF' > ~/.bashrc
alias k=kubectl
source <(kubectl completion bash)
EOF
source ~/.bashrc

k get nodes
k get po
k apply -f test.yaml
  • 安装 kubie 用于多集群和多 NS 管理
brew install kubie
echo 'alias kx=kubie' >> ~/.bashrc
source ~/.bashrc

mkdir -p ~/.kube/configs
cp zw1-cs1.yaml ~/.kube/configs/zw1-cs1.yaml
cp hs1-cs1.yaml ~/.kube/configs/hs1-cs1.yaml

kx ctx zw1-cs1
[zw1-cs1|default] k get node
[zw1-cs1|default] kx ns kube-system
[zw1-cs1|kube-system] k get po

  • 调试 node/pod

    k8s 1.25 引入临时容器可以进入容器 debug

# 进入 pod 调试
k debug <pod> -it --image=<debug-image>
k debug mypod -it --image=nicolaka/netshoot # 包含多种调试工具 image 

# 进入 node 调试
k debug node/<node> -it --image=<debug-image>
k debug node/gn-10-254-1-1 -it --image=busybox

kustomize#

阅读文章 https://kubectl.docs.kubernetes.io/

# 创建目录存放 yaml 文件
mkdir ollama && cd ollama

# 初始化
kustomize init

# 创建各种 yaml 文件
# 然后使用 kustomize 添加
kustomize edit add resource service.yaml

# 部署
kustomize build | k apply -f -
# 或者
k apply -k .

Helmwave#

阅读 https://docs.helmwave.app/

使用案例参考 CertManager

  1. 使用搜索引擎搜索对应项目 helm charts, 然后执行 helm repo add <name> <url> 添加
  2. 使用 helm search repo <name>/ 仓库下使用的具体版本
  3. 使用 helm show values <name>/<chart> 缺省值，一边后面自定义修改
  4. 创建需要自定义的 vaules.yml 文件
  5. 创建 helmwave.yml 描述文件
  6. 执行 helmwave up --build 部署服务
  7. 执行 helmwave down 卸载服务
