Kamaji#

Kamaji 是一个 Kubernetes Control Plane Manager，基于 Hosted Control Plane 概念，将 Kubernetes 控制平面组件作为 Pod 运行在管理集群中，而非独立机器上。通过这种方式，可以在单个管理集群中部署和管理多个租户 Kubernetes 控制平面，实现资源共享和优化利用。

核心特性#

  • 快速部署：租户控制平面可在 16 秒内启动
  • 快速升级：Kubernetes 版本升级仅需 10 秒
  • 资源优化：通过 Datastore 解耦节省高达 60% 的硬件资源
  • 多租户隔离：在单个管理集群内部署多个独立的 Kubernetes 控制平面
  • CNCF 合规：提供完全符合 CNCF 标准的 Kubernetes 集群
  • 上游兼容：使用未修改的上游 Kubernetes 组件

架构说明#

Kamaji 由以下核心组件构成：

  • Kamaji Operator：管理租户控制平面的生命周期
  • Tenant Control Plane：作为 Pod 运行的租户 Kubernetes 控制平面
  • Datastore：存储租户集群状态，支持 etcd、MySQL、PostgreSQL、NATS 等
  • Konnectivity：提供管理集群与租户工作节点之间的网络连接

准备工作#

  • 一个运行中的 Kubernetes 集群作为管理集群（推荐 v1.30+）
  • kubectl 已配置并可访问管理集群
  • helmwave 已安装（推荐方式）或 Helm 4.x
  • 准备 Datastore 后端（可选，默认使用内置 etcd）
  • cert-manager 已安装
  • local-storage 已安装

部署#

使用 helmwave 安装#

安装 Gateway API CRD：

kubectl apply --server-side -k crds-gateway-api

修改 values.yaml 根据实际环境配置参数，然后执行：

# 构建并部署
helmwave up --build

# 验证部署
kubectl get pods -n kamaji-system

验证安装#

# 检查 Kamaji Operator 状态
kubectl get pods -n kamaji-system

# 检查 CRD 是否安装
kubectl get crd | grep kamaji
# 应该看到：
# tenantcontrolplanes.kamaji.clastix.io
# datastores.kamaji.clastix.io

# 检查 Gateway API CRD 是否安装（Kamaji 需要）
kubectl get crd | grep gateway.networking.k8s.io
# 应该看到 TLSRoute 等 Gateway API CRD

部署示例租户集群#

  • mycluster

卸载#

删除示例租户集群#

kubectl delete -k https://github.com/clastix/kamaji/examples/mycluster

卸载 Kamaji#

helmwave down
