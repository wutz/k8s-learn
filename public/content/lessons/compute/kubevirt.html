KubeVirt#

施工中，不要用于生产环境

KubeVirt 是 Kubernetes 的虚拟机管理插件。其目标是在 Kubernetes 之上为虚拟化解决方案提供一个共同的基础。

准备#

  • 关闭 AppArmor/SELinux, 参见 os/os.md
  • 检查硬件虚拟机是否支持 virt-host-validate qemu
    • 如果命令不存在执行 apt install libvirt-clients -y
    • 如果输出为 QEMU: Checking for hardware virtualization: PASS 则表示硬件虚拟化支持
  • containerd 开启 device_ownership_from_security_context
    • 使用 kubespray 部署参见 containerd containerd_extra_runtime_args

部署#

# 部署 operator
kubectl apply -k operator

# 部署 kubevirt
kubectl apply -k cluster

# 部署 cdi, 使用 PVC 作为 KubeVirt 磁盘
kubectl apply -k cdi
