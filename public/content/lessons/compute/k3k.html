K3K#

K3k，即 Kubernetes 中的 Kubernetes，是一种能够让你在现有的 Kubernetes 环境中创建和管理隔离的 K3s 集群的工具。它支持高效的多租户模式、简化的实验流程和强大的资源隔离，通过允许你在同一物理主机上运行多个轻量级 Kubernetes 集群来降低基础设施成本。K3k 提供了“共享”模式，优化资源利用率，以及“虚拟”模式，提供完全隔离的专用 K3s 服务器 Pod。这让你能够无管理独立物理资源的额外开销，即可体验完整的 Kubernetes 功能。

部署 k3k#

helmwave up --build

管理集群#

# 部署虚拟集群
kubectl apply -f examples/k3k-virtual.yaml

# 查看集群信息
kubectl describe cluster k3k -n k3k-virtual
# 查看控制器日志
stern -n k3k-system .

# 删除虚拟集群
kubectl delete -f examples/k3k-virtual.yaml

卸载#

helmwave down
