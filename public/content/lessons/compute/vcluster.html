vCluster#

用于在 host k8s 上创建多个 virtual k8s 集群，以最大化利用资源

部署#

  • vCluster 命名：格式 vcluster-xxx, 需要修改:

    • helmwave.yaml 的 namespace
    • values.yaml 的 exportKubeConfig.context
    • nfd.yaml 的 metadata.name
    • netpol-cp.yaml 的 metadata.namespace
    • netpol-work.yaml 的 metadata.namespace

  • 准备节点用于 vCluster

    修改 nfd.yaml:

    • 多个 vCluster 共享节点, 只适合同一组织不同团队: 配置 scclabs.dev/node-pool: share
    • 一个 vCluster 独占节点, 适合不同组织: 配置 scclabs.dev/node-pool: vcluster-example
    • 最后配置节点池对应的 nodename 列表
kubectl apply -f nfd.yaml

  • 修改 values.yaml

    • 选择节点池：设置 sync.fromHost.nodes.selector.labels
    • 暴露 vCluster 服务
      • 以 Service LoadBalancer 暴露 vCluster 服务, 解开注释 controlPlane.service 并配置 annotations.metallb.universe.tf/loadBalancerIPs
      • 以 Ingress 暴露 vCluster 服务, 解开注释 ingress 并配置 controlPlane.ingress.spec.host 最后配置 exportKubeConfig.server 对应的地址
    • 配置网络策略: 根据实际情况修改需要让 vcluster 访问到 host k8s 相关服务, 配置 policies.networkPolicy.extraWorkerRules

  • 部署

helmwave up --build
  • 获取 kubeconfig （需要等待 1 分钟左右初始化）
kubectl get secrets -n vcluster-example vc-vcluster --template={{.data.config}} | base64 -D

卸载#

# 卸载 vCluster
helmwave down

# 移除 nfd
kubectl delete -f nfd.yaml
