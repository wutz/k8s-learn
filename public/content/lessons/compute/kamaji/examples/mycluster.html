创建租户集群#

1. 创建 Datastore（可选）#

如果使用默认的内置 etcd，可跳过此步骤。如果需要使用外部数据存储：

# 示例：使用外部 etcd
kubectl apply -f datastore.yaml

参考 datastore.yaml 配置示例。

2. 创建租户控制平面#

修改 tcp.yaml 配置示例。

kubectl apply -k .

3. 获取租户集群 kubeconfig#

# 获取 kubeconfig
kubectl get secret tenant-cluster-admin-kubeconfig -n default \
  -o jsonpath='{.data.admin\.conf}' | base64 -d > tenant-kubeconfig.yaml

# 测试连接
kubectl --kubeconfig=tenant-kubeconfig.yaml get nodes

4. 添加工作节点#

租户控制平面创建后，需要添加工作节点。可以使用以下方式：

  • 手动加入：使用 kubeadm join 命令
  • Cluster API：使用 Cluster API 提供商自动管理节点
  • 虚拟节点：使用 Virtual Kubelet 等方案

参考 join-worker-nodes.md 了解详细步骤。
