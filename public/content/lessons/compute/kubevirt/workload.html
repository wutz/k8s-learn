Workload#

安装 virtctl 客户端工具#

# macOS
brew install virtctl
virtctl -h

# krew
kubectl krew install virtctl
kubectl virt -h

简单示例#

# 创建虚拟机
kubectl apply -f cirros.yaml

# 查看状态
kubectl get vmi

# 连接控制台
virtctl console cirros

# 使用 ssh 连接, 密码 gocubsgo
virtctl ssh cirros@vmi/cirros

# 使用 vnc 连接, 需要安装 remote-viewer
brew tap jeffreywildman/homebrew-virt-manager
brew install remote-viewer
virtctl vnc cirros

# 使用 vnc 自定义客户端连接
virtctl vnc --proxy-only cirros
# 输出示例：
# Listening on 127.0.0.1:62316
# 然后使用 vnc 客户端连接 127.0.0.1:62316

故障排查:

  • 调度失败 (0/4 nodes are available: 1 Insufficient devices.kubevirt.io/kvm) 如果出现无法调度的问题，通常是因为节点不支持硬件虚拟化（KVM）。在开发环境中，可以通过开启软件模拟来解决，编辑 cluster/kubevirt.yaml 文件，取消 useEmulation 的注释，然后重新部署：
kubectl apply -f cluster/kubevirt.yaml

复杂示例#

依赖：

  • 部署 cdi
# 创建虚拟机
kubectl apply -f fedora.yaml
# 启动虚拟机
virtctl start fedora
# 使用 ssh 连接
virtctl ssh myuser@vmi/fedora
