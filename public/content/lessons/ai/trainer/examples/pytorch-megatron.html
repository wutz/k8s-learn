Pytorch Megatron 训练示例#

用途：基于 NVIDIA Megatron-LM 的 GPT 训练示例，支持单节点和多节点（RoCE 网络）模式。

工作流（一次性准备）#

1. 创建共享存储和开发容器#

kubectl apply -f pytorch-megatron-base.yaml

创建 PVC megatron-data 和开发容器 megatron-dev，后续存储均挂载在 /workspace 下，三调度器共享。

2. 在开发容器中准备数据集#

kubectl exec -it deploy/megatron-dev -- bash
cd /workspace
export http_proxy=http://10.29.1.201:8888
export https_proxy=http://10.29.1.201:8888
pip install modelscope datasets
modelscope download --dataset wutaizeng/enwiki --local_dir ./datasets

3. 在开发容器中准备训练代码#

cd /workspace
export http_proxy=http://10.29.1.201:3128
export https_proxy=http://10.29.1.201:3128
git clone -b core_v0.13.1 https://github.com/NVIDIA/Megatron-LM.git

提交训练#

TrainingRuntime 与 TrainJob#

  • TrainingRuntime：作业模板，定义存储挂载、镜像、资源等。存储挂载必须在此处定义。
  • TrainJob：训练任务实例，引用 TrainingRuntime，可覆盖模板的 image、command、env 等参数。

并行约束#

根据是否跨节点（即是否使用 RoCE 网络），选择不同的训练任务示例：

模式 numProcPerNode tensor-model-parallel-size pipeline-model-parallel-size 约束
单节点 = resources.limits.nvidia.com/gpu ≤ numProcPerNode 1 numProcPerNode 是 TP 的整数倍；TP > 1 时触发数据并行
多节点 = 8（满卡） = numProcPerNode（=8） numNodes 的约数 numNodes 是 PP 的整数倍

多节点训练作业 YAML 中已包含 RoCE 网络配置：

  • annotations.k8s.v1.cni.cncf.io/networks：挂载 8 个 Spiderpool NetworkAttachmentDefinition（hca1-hca8）
  • resources.limits.rdma/hca1-rdma/hca8：各 1
  • NCCL_IB_GID_INDEX=7：RoCE v2 + IP 行的 GID

提交命令#

# 单节点
kubectl apply -f volcano/pytorch-megatron-single-node.yaml

# 多节点（需 RoCE 网络）
kubectl apply -f volcano/pytorch-megatron-multiple-nodes.yaml

# 查看训练日志
kubectl logs -l trainer.kubeflow.org/trainjob-name=pytorch-megatron-single-node-train -f

其它调度器见下方调度器选择，将 volcano/ 替换为对应目录。

批大小约束#

  • --global-batch-size 必须是 --micro-batch-size × data-parallel-size 的整数倍
  • --micro-batch-size 越大训练越快，但显存占用更多，触发 OOM 时减小

多节点满 8 卡说明#

多节点训练必须满 8 卡使用，与 RoCE 网络相关（IB 不存在此问题）：

  • 一个节点启动多实例时，RoCE GID 是自增的，需要 Pod 启动时动态获取
  • 一个节点启动多实例时，申请 RoCE IP 容易触发上限

调度器选择#

调度器 推荐场景 目录
Volcano （默认） 多租户优先级抢占 volcano/
Kueue 多租户配额控制 kueue/
scheduler-plugins 基础验证、快速测试 scheduler-plugins/

关键参数#

参数 说明 适用场景
numProcPerNode 等于 resources.limits.nvidia.com/gpu 所有
NCCL_IB_GID_INDEX=7 RoCE v2 + IP 行的 GID 多节点
NCCL_IB_HCA=mlx5 指定 IB HCA 前缀 多节点
NCCL_IB_QPS_PER_CONNECTION=8 每连接 QP 数 多节点
NCCL_SOCKET_IFNAME=eth0 NCCL socket 网络接口 所有
