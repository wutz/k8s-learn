NVBandwidth#

用途：测量 GPU 系统的内存带宽和延迟（PCIe / NVLink / Host-Device 通信），每节点独立运行。

快速开始（默认 volcano）#

cd volcano/

kubectl apply -f nvbandwidth.yaml

# 查看每个节点的测试结果
kubectl get pods --no-headers -o custom-columns=POD:.metadata.name,NODE:.spec.nodeName | grep nvbandwidth | while read -r POD NODE; do
  echo "########## Node: ${NODE} (Pod: ${POD}) ##########"
  kubectl logs "${POD}"
  echo "=================================================================="
done

修改 mlPolicy.numNodes 调整测试节点数（默认 2）。

调度器选择#

默认推荐 Kueue，其他调度器按需选用：

调度器 推荐场景 目录
Volcano （默认） 多租户优先级抢占 volcano/
Kueue 多租户配额控制 kueue/
scheduler-plugins 基础验证、快速测试 scheduler-plugins/
