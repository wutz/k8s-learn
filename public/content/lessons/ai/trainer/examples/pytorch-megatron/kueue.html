Pytorch Megatron (Kueue)#

用途：基于 Megatron-LM 的 GPT 训练，多租户配额控制场景首选。

数据集和训练代码准备见上级目录 ../README.md。

快速运行#

# 单节点训练（4 GPU）
kubectl apply -f pytorch-megatron-single-node.yaml

# 多节点训练（2 节点 × 8 GPU + RoCE）
kubectl apply -f pytorch-megatron-multiple-nodes.yaml

# 查看训练日志
kubectl logs -l trainer.kubeflow.org/trainjob-name=pytorch-megatron-single-node-train -f
# 或
kubectl logs -l trainer.kubeflow.org/trainjob-name=pytorch-megatron-multiple-nodes-train -f

# 清理
kubectl delete -f pytorch-megatron-single-node.yaml

yaml 选择#

文件 节点数 每节点 GPU 总 GPU 网络
pytorch-megatron-single-node.yaml 1 4 4 普通
pytorch-megatron-multiple-nodes.yaml 2 8 16 RoCE（8 hca）

前置要求#

提交前验证：

# 1. 基础设施已部署（共享 PVC + 开发容器）
kubectl get pvc megatron-data
# 期望：STATUS=Bound

# 2. Kueue 队列就绪
kubectl get clusterqueue gpu-cluster-queue
kubectl get localqueue gpu-local-queue -n default
# 期望：均 Active

# 3. 配额充足
kubectl get clusterqueue gpu-cluster-queue -o jsonpath='{.spec.resourceGroups[0].flavors[0].resources[?(@.name=="nvidia.com/gpu")].nominalQuota}'
# 期望：单节点 ≥ 4，多节点 ≥ 16

# 4. 多节点训练额外要求
kubectl get net-attach-def -n spiderpool | grep hca
# 期望：spiderpool 下存在 hca1-hca8

# 5. 节点资源已注册
kubectl get node <node-name> -o jsonpath='{.status.allocatable}' | jq '."nvidia.com/gpu", ."rdma/hca1"'
# 期望：单节点 GPU ≥ 4；多节点 GPU=8 + rdma/hca1-8 各 ≥ 1

预期输出#

训练日志显示 loss 下降 + iteration time + throughput：

 iteration       100/  500000 | consumed samples:        ... | elapsed time per iteration (ms): ... | throughput per GPU (TFLOP/s/GPU): ... | learning rate: ... | global batch size: ... | lm loss: ...

观察状态#

kubectl get workload -l kueue.x-k8s.io/job-uid
kubectl get trainjob
kubectl get pod -l trainer.kubeflow.org/trainjob-name=pytorch-megatron-single-node-train

任务初始为 suspend=true，Kueue 配额充足时自动 admit 并启动。
