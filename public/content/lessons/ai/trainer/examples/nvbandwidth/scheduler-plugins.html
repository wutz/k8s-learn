NVBandwidth (scheduler-plugins)#

用途：测量 GPU 内存带宽和延迟（PCIe / NVLink / Host-Device），基础环境验证场景。

快速运行#

# 提交测试
kubectl apply -f nvbandwidth.yaml

# 查看每个节点的测试结果
kubectl get pods --no-headers -o custom-columns=POD:.metadata.name,NODE:.spec.nodeName | grep nvbandwidth | while read -r POD NODE; do
  echo "########## Node: ${NODE} (Pod: ${POD}) ##########"
  kubectl logs "${POD}"
  echo "=================================================================="
done

# 清理
kubectl delete -f nvbandwidth.yaml

修改 yaml 中 mlPolicy.numNodes 调整测试节点数（默认 2）。

前置要求#

# 1. scheduler-plugins-scheduler Running
kubectl get pod -n scheduler-plugins-system

# 2. 节点 GPU 已注册
kubectl get node <node-name> -o jsonpath='{.status.allocatable.nvidia\.com/gpu}'
# 期望：8（或更多）

预期输出#

每个 Pod 日志末尾 SUM ... GB/s 接近 PCIe/NVLink 理论带宽即正常。
