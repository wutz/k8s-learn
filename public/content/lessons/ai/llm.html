LLM#

当前社区推理框架大多部分实现功能，故而本解决方案尝试使用社区通用推理组件进行组装一个推理框架

此解决方案采用通过推理组件：

  • 推理网关：Gateway API Inference Extension (GIE/IGW) 推理网关标准定义
  • 推理负载管理: Role Based Group (RBG) 通用推理负载管理, 潜力标准定义

部署基础服务#

依赖组件:

  • 部署 MetalLB 提供南北负载均衡服务
  • 部署 KGateway 提供网关与推理网关服务
  • 部署 Storage 提供共享存储存放模型文件
  • 部署 RBG 提供推理负载管理

修改基础服务配置：

  • gateway 部署网关服务，可以自定义端口
  • pvc 部署共享存储，用于存放模型文件，可以自定义存储类型与大小
  • deploy 部署开发机，用于拉取模型文件，待启动容器进入后可以执行下面命令拉取模型文件
# 例如拉取 Qwen3-32B 模型文件
modelscope download --model Qwen/Qwen3-32B --local_dir /models/Qwen/Qwen3-32B

执行下面步骤完成基础服务:

cd base
helmwave up --build

部署推理服务示例#

  • vllm-sim 部署 vllm 模拟推理服务，适用于开发测试
  • vllm-sts 部署 vllm 推理服务，适用于多个单节点推理
