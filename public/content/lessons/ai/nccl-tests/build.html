构建 nccl-tests 镜像#

# 构建镜像
docker build --platform linux/amd64 -t mir.blsc.cn/library/coreweave/nccl-tests:13.1.0-devel-ubuntu22.04-nccl2.29.2-1-2276a5e-mpi1 .

# 推送到镜像仓库
docker push mir.blsc.cn/library/coreweave/nccl-tests:13.1.0-devel-ubuntu22.04-nccl2.29.2-1-2276a5e-mpi1

构建后验证#

构建完镜像本地跑一下，确认 mpiuser、sshd_config、hostkey 都到位：

TAG=mir.blsc.cn/library/coreweave/nccl-tests:13.1.0-devel-ubuntu22.04-nccl2.29.2-1-2276a5e-mpi1

# 1. 验证 mpiuser 存在 (uid 1000)
docker run --rm --user 1000 $TAG id
# 预期: uid=1000(mpiuser) gid=1000(mpiuser) groups=1000(mpiuser)

# 2. 验证 sshd_config 与 hostkey 文件就位且 mpiuser 可读
docker run --rm --user 1000 $TAG ls -la \
    /home/mpiuser/.sshd_config \
    /home/mpiuser/ssh_host_rsa_key

# 3. 验证 sshd 能用 mpiuser 起来 (前台运行 5 秒后自杀)
docker run --rm --user 1000 $TAG bash -c \
    'timeout 5 /usr/sbin/sshd -De -f /home/mpiuser/.sshd_config; echo "exit=$?"'
# 预期看到: Server listening on 0.0.0.0 port 2222

推送后验证#

# 4. 验证 registry 收到正确 digest
docker pull $TAG
docker images --digests | grep 2276a5e-mpi1

# 5. 节点上确认拉到新版本 (yaml 里建议 imagePullPolicy: Always)
#    或在节点上手动清理旧镜像: crictl rmi <旧 sha>

tag 命名约定#

每次修改 Dockerfile 或 sshd_config，递增 -mpiN 后缀：

  • -mpi1：首版（修复 mpiuser/hostkey/sshd_config）
  • -mpi2：下次修改时使用
  • ...

不要复用同一个 tag，否则节点 IfNotPresent 缓存会让你怀疑人生。
