配置参考#

基于当前 5 个 YAML 的实际配置编写。参数说明见各章节表格。

NCCL 环境变量#

通用参数（所有机型一致）#

参数 值 说明
NCCL_ALGO Ring 固定 Ring 算法，确保结果可比
NCCL_IB_DISABLE 0 启用 IB/RoCE，禁用则回退 TCP 带宽暴跌
NCCL_IB_QPS_PER_CONNECTION 8 每连接 8 个 QP，提升带宽利用率
NCCL_DEBUG WARN 仅输出警告，避免 INFO 日志过大触发轮转

按机型差异参数#

参数 5090 (hostnet) 5090 (macvlan) B200 B300 A100 (macvlan)
UCX_NET_DEVICES — — bond1 bond1 eth0
NCCL_SOCKET_IFNAME bond0 eth0 bond1 bond1 eth0
NCCL_IB_HCA mlx5 mlx5 mlx5 roce_vf_rail ^=mlx5_4
NCCL_IB_TC — — 106 106 —
NCCL_CROSS_NIC — — 1 1 —
NCCL_DEBUG_SUBSYS — — — — INIT,NET,GRAPH

参数说明：

参数 选错后果
UCX_NET_DEVICES UCX 选错网卡，hcoll 初始化失败或走错路径
NCCL_SOCKET_IFNAME 节点间 TCP 控制通道不通，无法连接
NCCL_IB_HCA 走错网卡或不走 RDMA，结果失真
NCCL_IB_TC 不设则 RoCE 流量无优先级标记，可能被拥塞丢弃
NCCL_CROSS_NIC 多网卡环境下不启用跨卡聚合，带宽利用率低
NCCL_DEBUG_SUBSYS 仅调试用，不影响功能

hcoll 禁用说明#

nccl-tests 中 MPI 仅作进程启动器，集合通信走 NCCL，不经过 hcoll。如遇 hcoll 初始化冲突，禁用即可：

  • 5090 系列：取消注释 -mca coll_hcoll_enable 0
  • B200/B300：取消注释 -x OMPI_MCA_coll_hcoll_enable=0

all_reduce_perf 参数#

当前配置#

参数 5090 5090-macvlan B200 B300 A100 含义
-b 8 8 8 8 8 起始数据量
-e 8G 8G 16G 64G 8G 结束数据量
-f 2 2 2 2 2 乘数步长（每次翻倍）
-g 1 1 1 1 1 每 rank 1 GPU

未显式指定时使用 nccl-tests 默认值：-n 20（迭代次数）、-w 1（预热）、-c 1（正确性校验）。

单次测试 vs 压力测试#

单次测试 压力测试
命令 -b 8 -e 8G -f 2 -g 1 -b 8G -e 8G -i 0 -g 1
数据量 8B→8G 翻倍扫描 固定 8G 不变
行为 扫描完自动退出 持续循环，手动停止
目的 性能曲线 + 正确性 满载带宽长稳

压力测试中 -i 0（stepbytes=0）使数据量不递增，配合 -b 8G -e 8G（min=max）程序持续循环输出 8G 行，直到 kubectl delete 停止。

集群规模适配#

当前 YAML 默认 2 节点 16 GPU。扩展节点数修改两处：

字段 位置 默认值 N 节点改为
numNodes mlPolicy 2 N
-np mpirun 16 N × 8

以 4 节点为例：

sed -e 's/numNodes: 2/numNodes: 4/' \
    -e 's/-np 16/-np 32/' \
    nccl-tests-5090.yaml > nccl-tests-5090-4node.yaml

性能基准#

理论峰值 busbw 计算公式：

理论峰值 = 网卡数 × 单口带宽 ÷ 8

busbw 校正因子（all_reduce）：2(n-1)/n，n 为 GPU 总数。此因子使 busbw 可与硬件峰值直接比较，与 rank 数量无关。

评级 busbw / 理论峰值
优秀 ≥ 90%
可接受 80–90%
异常 < 80%

具体理论峰值因集群网卡配置而异，由工程师根据硬件规格计算。
