Kubeflow Trainer#

Kubeflow Trainer 是 Kubeflow 的分布式训练控制器，提供统一的 CRD TrainJob 和 TrainingRuntime 抽象，支持 PyTorch / MPI / Jax / PaddlePaddle 训练框架，简化多节点训练任务编排。

核心能力：

  • 统一的 CRD 抽象（TrainJob + TrainingRuntime），屏蔽 PyTorchJob / MPIJob 等底层差异
  • 原生支持 Gang 调度（通过 Kueue / Volcano / scheduler-plugins）
  • 自动注入分布式训练环境变量（rank / world_size / master_addr 等）
  • Jobset-based 多副本管理（launcher / worker 分离）

本目录包含 Trainer v2.2.0 的 Helm 部署配置和生产级示例（examples/）。

依赖#

必需#

  • Kubernetes 1.27+
  • NVIDIA GPU Operator（或等效的 GPU device plugin）

调度器（三选一，默认推荐 Kueue）#

调度器 推荐场景 部署目录
Volcano （默认） 多租户优先级抢占、公平调度 ../volcano/
Kueue 多租户配额控制、作业排队 ../kueue/
scheduler-plugins 基础验证、快速测试（生产勿用） ../scheduler-plugins/

本 README 假设已部署 Volcano，其他调度器见 examples/<示例>/kueue/ 或 examples/<示例>/scheduler-plugins/ 子目录。

部署#

helmwave up --build

部署到 kubeflow-system namespace，包含：

  • Trainer controller manager（2 副本 HA）
  • 内置 TrainingRuntime CRD（torch-distributed / mpi / jax / paddle）

验证部署：

kubectl get deploy -n kubeflow-system kubeflow-trainer-trainer-controller-manager
kubectl get trainingruntimes -n default

快速验证#

部署后跑一个极简示例：

# PyTorch 单节点 1 GPU
kubectl apply -f examples/pytorch-simple.yaml
kubectl logs -l trainer.kubeflow.org/trainjob-name=pytorch-simple-train -f

# MPI 单节点 1 GPU
kubectl apply -f examples/mpi-simple.yaml
kubectl logs -l trainer.kubeflow.org/replicated-job-name=launcher -f

输出 Hello from rank X 即部署正常。

配置说明#

values.yaml 关键参数#

image:
  tag: "sha-ec31ebe"         # Trainer v2.2.0 镜像 SHA（对应 GitHub commit）

manager:
  replicas: 2                 # 控制器副本数（HA）

runtimes:
  defaultEnabled: true        # 部署所有内置 TrainingRuntime（torch / mpi / jax / paddle）

生产环境建议：

  • manager.replicas: 2（HA）
  • 固定 image.tag（避免 latest 标签不确定性）

卸载#

# 清理所有示例（可选）
kubectl delete trainjobs --all
kubectl delete pods -l trainer.kubeflow.org/trainjob-name

# 卸载 Trainer
helmwave down
