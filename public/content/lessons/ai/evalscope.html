EvalScope#

EvalScope 是一个由 ModelScope 社区精心打造的综合性模型评估和性能基准测试框架，为您的模型评估需求提供一站式解决方案。

性能测试#

# 安装 evalscope
pip install evalscope[perf] -i https://mirror.ustc.edu.cn/pypi/simple

ADDRESS=<IP_ADDRESS_OR_DOMAIN>
evalscope perf \
    --url http://$ADDRESS/v1/chat/completions \
    --model vllm/Qwen/Qwen3-32B \
    --tokenizer-path Qwen/Qwen3-32B \
    --dataset random \
    --parallel 1 10 50 100 150 200 \
    --number 2 20 100 200 300 400 \
    --max-prompt-length 4096 \
    --min-prompt-length 4096 \
    --prefix-length 0 \
    --max-tokens 1024 \
    --min-tokens 1024 \
    --extra-args '{"ignore_eos": true}'
  • -tokenizer-path 指定模型的 tokenizer 路径, 自动从 ModelScope 下载
  • parallel 并发数与 number 请求数一一对应
  • 生成的输入长度在 prefix_length + min-prompt-length 到 prefix_length + max-prompt-length 之间均匀分布，单个测试所有请求具有相同的 prefix 内容

参数见 EvalScope Perf
