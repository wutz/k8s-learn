vllm-sts#

演示使用 vllm 部署推理服务，使用 StatefulSet 部署，适用于多个单节点推理

部署#

根据环境需要修改：

  • rbg.yaml 部署 sglang 负载服务
    • --model-path 和 --served-model-name 设置模型路径和名称
    • --hicache-size 200 设置 KV Cache 卸载到 Host Memory 200 GB, 其值应小于 resources.limits.memory
    • resources.limits 设置 CPU、内存、GPU
helmwave up --build

查看日志：

stern sts-sglang |grep -v metrics
  • HiCache 相关记录
    • Allocating 199.98 GB host memory for hierarchical KV cache

访问#

IP=$(kubectl get gateway/inference-gateway -o jsonpath='{.status.addresses[0].value}')
PORT=80

curl -i ${IP}:${PORT}/v1/completions -H 'Content-Type: application/json' -d '{
"model": "sglang/Qwen/Qwen3-32B",
"prompt": "Write as if you were a critic: San Francisco",
"max_tokens": 100,
"temperature": 0
}'
