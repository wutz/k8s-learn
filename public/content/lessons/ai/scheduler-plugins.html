scheduler-plugins#

提供额外功能调度器, 例如提供批量调度等

安装#

helmwave up --build

使用#

  • 创建 PodGroups
  • 在 Pod 中设置 schedulerName: scheduler-plugins-scheduler 以及 label scheduling.x-k8s.io/pod-group: xxx
# 创建 PodGroup 需要至少 3 Pod 一起调度
# 但是只要 2 个 Pod
kubectl apply -f tests.yaml

# Pod 均处于 Pending 状态
kubectl get pod

# 扩容到 3 个 Pod 后, 所有 Pod 均处于 Running 状态
kubectl scale deploy pause --replicas=3
kubectl get po

卸载#

helmwave down
