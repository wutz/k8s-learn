FoundationDB#

Alpha

提供分布式带事物支持的 KV 数据库, 可以用于文件系统的元数据服务使用。

常见支持使用 FDB 的文件系统有：

  • 3fs
  • juicefs

部署#

# 部署 operator
kubectl apply -k operator/

# 部署 cluster
# * 修改 bj1fdb01.yaml 中的配置 2 处 name
# * 修改 storageClassName 实际本地 NVMe SSD 文件系统
kubectl apply -f bj1fdb01.yaml

使用#

# 使用 fdbcli 连接到集群
kubectl exec -it bj1fdb01-log-18832 -- fdbcli

fdbcli 下常用命令：

  • status details 查看集群状态

卸载#

# 卸载 operator
kubectl delete -k operator/

# 卸载 cluster
kubectl delete -f bj1fdb01.yaml
