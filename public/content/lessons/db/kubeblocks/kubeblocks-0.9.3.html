Kubeblocks#

安装#

  1. 安装 Kubeblocks
helmwave up --build

卸载#

  1. helmwave down
  2. kubectl delete -f hooks/crds.yaml

备份#

  1. 配置备份仓库

使用 pvc shared-nvme 作为 BackupRepo

# 执行前需要修改文件中的storageClassName名称
kubectl apply -f hooks/backuprepo/prod/backuprepo-pvc.yaml

使用 S3 对象存储 作为 BackupRepo

# 执行前需要修改文件中的AK/SK，桶名，S3地址等信息
kubectl apply -f hooks/backuprepo/prod/backuprepo-s3.yaml

开启监控组件#

启用监控组件#

kubectl apply --server-side --force-conflicts -f hooks/kb-addon-alertmanager-configmap.yaml
kubectl apply --server-side --force-conflicts -f hooks/kb-addon-enable-alertmanager-webhook.yaml
kubectl apply --server-side --force-conflicts -f hooks/kb-addon-enable-alertmanager.yaml
kubectl apply --server-side --force-conflicts -f hooks/kb-addon-enable-grafana.yaml
kubectl apply --server-side --force-conflicts -f hooks/kb-addon-enable-prometheus.yaml

待监控组件都启动完成。

更新监控配置#

kubectl apply --server-side --force-conflicts -f hooks/kb-addon-mysql-grafana-mysql.yaml
kubectl apply --server-side --force-conflicts -f hooks/kb-addon-postgresql-grafana-postgresql.yaml
kubectl apply --server-side --force-conflicts -f hooks/kb-addon-prometheus-server.yaml
kubectl apply --server-side --force-conflicts -f hooks/kb-addon-redis-grafana-redis.yaml

重启组件使配置生效

kubectl rollout restart sts/alertmanager sts/kb-addon-prometheus-server

启动示例#

# 启动postgresql 集群
kubectl apply -f examples/postgresql/harbor-database.yaml

# 启动redis集群
kubectl apply -f examples/redis/harbor-cache.yaml
