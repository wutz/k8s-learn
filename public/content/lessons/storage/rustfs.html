RustFS#

minio 平替

RustFS 是一个高性能、分布式的对象存储系统，基于 Rust 构建，Rust 是全球最受欢迎的编程语言之一。RustFS 将 MinIO 的简单性与 Rust 的内存安全和原始性能相结合。它提供了完全符合 S3 标准的功能，完全开源，并针对数据湖、人工智能和大数据工作负载进行了优化。

单机部署#

docker run -d \
  --name rustfs \
  --net host \
  --restart always \
  -v $PWD/data:/data \
  rustfs/rustfs:latest

访问 http://localhost:9001 访问控制台, 默认用户名和密码为 rustfsadmin/rustfsadmin
