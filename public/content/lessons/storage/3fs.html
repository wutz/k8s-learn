3FS#

Fire-Flyer File System (3FS) 是一种高性能分布式文件系统，旨在应对 AI 训练和推理工作负载的挑战。它利用现代 SSD 和 RDMA 网络来提供一个共享存储层，从而简化分布式应用程序的开发。

在 Kubernetes 上部署 3FS 使用项目 kvc-3fs-operator 来管理 3FS 集群的生命周期。

部署#

  • 元数据与数据存储可用容量配比 4.8GiB : 1TiB
  • 元数据存储至少 3 个节点，每个节点配置独立 SSD, 可以使用 3 个管理节点
mkfs.xfs -L data0 /dev/nvme0n1
mkdir -p /opt/3fs
cp /etc/fstab{,.orig}
echo "LABEL=data0 /opt/3fs xfs defaults,noatime,nodiratime 0 0" >> /etc/fstab
mount -a
  • 数据存储至少 2 个节点，每个节点配置 RDMA 网卡和独立 SSD, 可以使用 GPU 节点
seq 0 3 |xargs -I{} mkfs.xfs -L data{} /dev/nvme{}n1
mkdir -p /data{0..3}
cp /etc/fstab{,.orig}
seq 0 3 |xargs -I{} echo "LABEL=data{} /data{} xfs defaults,noatime,nodiratime 0 0" >> /etc/fstab
mount -a
