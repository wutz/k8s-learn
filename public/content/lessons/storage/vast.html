Vast#

Vast 是统一存储系统，类似 Ceph 可以提供文件系统，块存储和对象存储服务

添加集群连接信息#

从租户管理员获取信息，修改 cluster:

  • 自定义 secret name: 格式推荐 <cluster>-<tenant>, 例如 bz1-vast1-test1
  • endpoint: 集群控制 API 的地址, 例如 vms.vast1.bz1.paratera.com
  • tenant: 分配的租户名称, 例如 test1
  • username & password: 连接租户的用户名和密码

执行 kubectl apply -k cluster 部署连接集群的 secret

NFS CSI#

主要提供 NFS 服务的 CSI，相比社区 NFS CSI 支持 Quota 和 QoS 等高级特性

修改 nfs values 中 storageClasses 下配置

  • key: 表示创建的 storageClassName, 例如 shared-vast
  • secretName: 集群租户的 API 服务连接信息，见 "添加集群连接信息"
  • vipPoolFQDN: nfs 挂载 server 地址名称（被DNS解析），例如 main.vast1.bz1.paratera.com
  • vipPoolFQDNRandomPrefix: 是否在 vipPoolFQDN 前面添加随机前缀，使用外置 DNS 解析时(当前使用此方式), 必须设置 false
  • storagePath: 租户内唯一 path，可以根据业务和集群名称等自定义, 由 CSI 自动创建，推荐使用格式 /<cluster>/<fs>, 例如 /dev1/fs1
  • viewPolicy: 租户管理员预创建的 nfs 访问策略，通常用于允许哪些 client ip 挂载文件系统, 推荐格式使用 <cluster>, 例如 dev1
  • qosPolicy: 租户管理预创建的缺省 QoS 策略，通常为租户的名称，例如 test1, 缺省为 BW：1GB/s, IOPS: 10000
  • mountOptions: 性能优化挂载选项
    • vers=3 使用 nfs 3 版本, 无状态，数据一致性好
    • nconnect=16 nfs 连接 server 的 tcp 连接数量，用于提升吞吐

部署：

cd nfs
helmwave up -d

测试:

# 部署 PVC
kubectl apply -f tests/pvc.yaml
# 测试 PVC
kubectl exec -it tests-vast-nfs-pod -- sh

Block CSI#

前置依赖：

  • 安装 nvme-cli 工具 apt install -y nvme-cli

主要提供块存储服务 CSI

修改 block values 中 storageClasses 下配置:

  • key: 表示创建的 storageClassName, 例如 block-vast
  • secretName: 集群租户的 API 服务连接信息，见文档开始
  • vipPoolFQDN: nfs 挂载 server 地址名称（被DNS解析），例如 test1.vast1.bz1.paratera.com
  • storagePath: 租户管理员创建，租户内唯一 path，可以根据业务和集群名称等自定义, 推荐使用格式 /<cluster>/<block>, 例如 /dev1/block1
  • viewPolicy: 租户管理预创建的访问策略，推荐格式使用 <cluster>, 例如 dev1
  • qosPolicy: 当前版本不支持，下一版本 Vast 5.4 支持，租户管理预创建的缺省 QoS 策略，缺省为 BW：1GB/s, IOPS: 10000
  • subsystem: 租户管理员分配的 NVMe 命名空间名称，推荐格式 <cluster>-<block>，例如 dev1-block1
  • snapshotClasses（可选）: 支持快照，填写集群租户的 API 服务连接信息，见文档开始，依赖部署 volumesnapshots CRDs

部署：

cd block
helmwave up -d

测试:

# 部署 PVC
kubectl apply -f tests/pvc.yaml
# 测试 PVC
kubectl exec -it tests-vast-block-pod -- sh

# 部署快照
kubectl apply -f tests/pvc-snap.yaml
# 部署克隆
kubectl apply -f tests/pvc-snap-clone.yaml
# 测试克隆
kubectl exec -it tests-vast-block-pod-clone -- sh
