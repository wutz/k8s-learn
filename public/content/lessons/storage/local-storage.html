local-storage#

local-storage 是一个 Kubernetes 本地存储解决方案，它使用本地磁盘作为存储后端，为 Kubernetes 提供本地存储服务。

部署#

kubectl apply -k .

# 等待所有 pod 就绪
kubectl wait -n local-path-storage --for=condition=ready pod -l app=local-path-provisioner

测试#

kubectl apply -f tests/local-path.yaml
kubectl exec -it local-path-pod -- bash
kubectl delete -f tests/local-path.yaml

添加本地 nvme ssd 的 storageClass local-nvme#

例如，添加 /dev/nvme0n1 其挂载路径为 /data1

  1. 格式化 /dev/nvme0n1 并挂载到 /data1
  2. 修改 patch.yaml 中 local-nvme 下的 paths 值
  3. 取消注释 kustomization.yaml 中的 local-nvme.yaml 部分
  4. 更新 kubectl apply -k .
  5. 测试 kubectl apply -f tests/local-nvme.yaml

添加共享文件系统 storageClass shared-fs#

  • 可以根据需要自定义 storageClass 名称
  • 适用于 GPFS 启用多租户下原生 CSI 由于权限无法的场景使用，通过此 CSI 的限制不支持设置 Quota 和 QoS
  1. 共享文件系统挂载到 /fs0
  2. 修改 patch.yaml 中 shared-fs 下的 sharedFilesystemPath 值
  3. 取消注释 kustomization.yaml 中的 shared-fs.yaml 部分
  4. 更新 kubectl apply -k .
  5. 测试 kubectl apply -f tests/shared-fs.yaml

卸载#

kubectl delete -k.
