GPFS CSI Driver部署说明#

1 前置条件#

假设本次部署的GPFS服务端有10个节点，分别是172.18.3.[193-202]

假设本次部署GPFS GUI服务的节点2个，分别是172.18.3.[203-204]

1.1 部署方案#

部署GPFS CSI Driver前，需要先部署GPFS存储集群，并且需要同时部署好GUI服务。

通常GPFS服务端和客户端的部署方式分为两种：

  1. 所有客户端加入到服务端集群。
  2. 服务端集群和客户端集群分开部署。

第一种【所有客户端加入到服务端集群】部署方式比较简单，要求：

  1. 所有客户端节点加入到GPFS服务端集群。
  2. 统一配置集群内所有节点的/etc/hosts文件，所有节点保持一致。
  3. 所有客户端节点要求与服务端仲裁节点免密。
  4. 用一套GUI服务。

第二种【服务端集群和客户端集群分开部署】部署方式要求：

  1. 服务端集群和客户端集群分别部署。
  2. 服务端集群和客户端集群分别配置/etc/hosts文件，保持一致。
  3. 客户端集群有自己独立的仲裁节点。
  4. 服务端集群仲裁节点和客户端集群仲裁节点配置免密登录。
  5. 客户端仲裁节点要和其他客户端节点免密。
  6. 服务端集群有自己独立的GUI服务。
  7. 客户端集群有自己独立的GUI服务。

本环境使用的是第一种部署方式

1.2 部署前置要求#

部署GPFS CSI Driver前，需要先部署GPFS存储集群，并且需要同时部署好GUI服务。

所有客户端节点需要挂载好GPFS文件系统。本环境客户端挂载点为 /mnt/gpfs1

2 部署GPFS CSI Driver#

2.1 配置GPFS集群#

以下步骤在GUI服务节点172.18.3.203上执行

# 查看 GUI 用户
/usr/lpp/mmfs/gui/cli/lsuser

# 查看 GUI 用户组
/usr/lpp/mmfs/gui/cli/lsusergrp

# 创建 CsiAdmin 用户组(默认已经存在)
/usr/lpp/mmfs/gui/cli/mkusergrp CsiAdmin --role csiadmin

# 创建 csiuser 用户，使其归属于 CsiAdmin 用户组
# 该用户会用于 SCI 驱动程序
/usr/lpp/mmfs/gui/cli/mkuser csiuser -p csipassword -g CsiAdmin

以下服务在GPFS第一个仲裁节点172.18.3.193上执行

# 设置配额
/usr/lpp/mmfs/bin/mmchfs defaultfs -Q yes

# 验证文件系统配置
# 确保 perfileset-quota 参数值为 no
/usr/lpp/mmfs/bin/mmlsfs defaultfs --filesetdf -Q --perfileset-quota

# 对于 Red Hat OpenShift 的特定参数
/usr/lpp/mmfs/bin/mmchconfig controlSetxattrImmutableSELinux=yes

# 设置在容器中显示正确的卷大小
/usr/lpp/mmfs/bin/mmchfs defaultfs --filesetdf

# 启用自动 inode 扩展
# 该功能仅限于 IBM Storage Scale 5.1.4 及以上的版本
# 启用此设置后，文件集上指定的 inode-limit 设置将被忽略
/usr/lpp/mmfs/bin/mmchfs defaultfs --auto-inode-limit

启用对 root 用户施加 fileset quota 限制，只需在访问集群（accessing cluster）上执行。本环境客户端与服务端为同一集群，直接在客户端挂载节点上执行即可：

/usr/lpp/mmfs/bin/mmchconfig enforceFilesetQuotaOnRoot=yes -i

如果在开启 enforceFilesetQuotaOnRoot 之前已经写入过数据，需要在拥有集群（owning cluster）上执行 mmcheckquota defaultfs 重新核算配额用量，否则已有用量统计不准，可能出现无法写入的情况。

2.2 配置Kubernetes集群#

执行前确认GPFS已挂载到Kubernetes集群的所有节点上，本环境是/mnt/gpfs1。

以下步骤在Kubernetes上执行

# 创建命名空间
kubectl create ns gpfs-csi

# 为所有Kubernetes节点增加标签
# 本环境需要为mn、gn节点增加标签
kubectl label node mn01.zw1.local scale=true --overwrite=true
