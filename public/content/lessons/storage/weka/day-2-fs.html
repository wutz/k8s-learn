Weka 文件系统管理#

创建组织#

  • 最大支持 256 个组织
  • 每个组织一个组织管理员
  • 缺省组织为 root
  • 使用 ClusterAdmin 创建新组织
  • 必须为每个租户创建一个组织管理员来分离权限
  • 创建组织设置 Total Quota 即可

例如为 deepseek 租户创建组织 deepseek 且管理员为 deepseek-admin, 并设置 100Ti 存储容量:

# 使用集群管理员登录
weka user login

# 创建组织, 用户名前使用组织缩写方便区分
weka org add deepseek1 ds1admin <password> --total-quota 100TiB

# 查看组织列表
weka org

GUI 管理参见 组织管理

创建用户#

为不同用途创建不同权限的用户:

# 使用组织管理员登录组织 deepseek1
weka user login ds1admin --org deepseek1

# 创建 Regular 用于 Linux 挂载使用
weka user add ds1mount regular <password>
# 创建 CSI 权限用户用于 K8S 集群使用
weka user add ds1csi csi <password>

# 查看用户列表
weka user

GUI 管理参见 用户管理

创建文件组#

  • 主要用于存储分层策略设置
  • weka 最多支持 8 个文件组
  • 可以只创建一个复用
# 使用集群管理员 admin 登录
weka user login admin --org root

# 创建文件组 default
weka fs group create default

GUI 管理参见 文件组管理

创建文件系统#

  • weka 支持最多 1024 个文件系统
  • 不再 root 组织下创建文件系统，如果需要则必须开启认证挂载
# 使用组织管理员 ds1admin 登录组织 deepseek1
weka user login ds1admin --org deepseek1

# 创建文件系统 ds1fs1 配置使用 thin 模式，容量上限为 50TiB
weka fs add ds1fs1 default 50TiB --thin-provision-min-ssd 1GiB --thin-provision-max-ssd 50TiB

# 查看文件系统列表
weka fs
