WekaFS CSI 部署#

前置#

  • Weka 客户端已在 K8S 节点完成安装
  • 组织管理员提供下面信息
    • organization
    • username
    • password
    • endpoints
    • filesystem

部署#

helmwave up --build

部署 storageclass shared-weka:

  • 修改 shared-weka/secret.yaml 中下面字段:
    • username
    • password
    • organization
    • endpoints
  • 修改 shared-weka/storageclass.yaml 中 filesystemName 字段
# 部署 shared-weka
kubectl apply -k shared-nvme/

# 测试
kubectl apply -f tests.yaml
# 访问容器查看
kubectl exec -it tests-weka -- bash
> df -h

卸载#

# 删除 storageclass = shared-weka
kubectl delete -k shared-nvme/

# 卸载 weka csi
helmwave down
