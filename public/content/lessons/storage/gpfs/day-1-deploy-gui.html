部署 GUI#

GUI服务节点只配置管理网，不用配置数据网。

GUI服务节点需要和集群内所有节点免密。

GUI服务节点需要部署在服务端集群和客户端集群。

部署 GPFS#

把GUI服务节点的IP和主机名关系加入到指定集群节点的/etc/hosts文件中。

做好GUI服务节点到集群内其他节点的免密。

去掉如下提示，防止GUI脚本执行失败 The authenticity of host ... can't be established. Are you sure you want to continue connecting (yes/no/[fingerprint])?

cat << 'EOF' >> /etc/ssh/ssh_config.d/99-gpfs.conf
Host *
    StrictHostKeyChecking no
    UserKnownHostsFile /dev/null
EOF

部署 GUI#


# 安装依赖
dnf install kernel-devel-$(uname -r) kernel-headers-$(uname -r) make gcc elfutils-libelf-devel

# 安装全部软件包
cd gpfs_rpms
yum install *.rpm
/usr/lpp/mmfs/bin/mmbuildgpl

# 初始化postgresql数据库
/usr/bin/postgresql-setup --initdb

# 安装pmcollector和pmsensors
cd zimon_rpms
yum install gpfs.gss.*.rpm

# 在集群仲裁节点上把GUI节点加入到集群
mmaddnode -N gui-10-1-120-222
mmchlicense client --accept -N gui-10-1-120-222

# 启动gui服务
systemctl start gpfsgui.service

# 初始化GUI节点服务
/usr/lpp/mmfs/gui/cli/initgui

# 创建GUI管理员
# https://www.ibm.com/docs/en/storage-scale/5.2.2?topic=administering-managing-gui-users
/usr/lpp/mmfs/gui/cli/mkuser admin -g SecurityAdmin -p 'Admin@123'

# 管理员密码不过期
/usr/lpp/mmfs/gui/cli/chuser admin -e 1

# 初始化pmcollector
/usr/lpp/mmfs/bin/mmperfmon config generate --collectors gui-10-1-120-222

# 启动pmcollector
systemctl enable pmcollector --now

# 启动pmsensors
# 启动前需要确认所有节点都已经安装好pmsensor包。
 /usr/lpp/mmfs/bin/mmchnode --perfmon -N all

# 创建csi专用用户
/usr/lpp/mmfs/gui/cli/mkuser csiuser1 -p xxxxxx -g CsiAdmin
/usr/lpp/mmfs/gui/cli/chuser csiuser1 -e 1
