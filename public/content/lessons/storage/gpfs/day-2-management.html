GPFS 管理#

文件集管理#

  • 在 fileset 上施加 quota 和 qos 限制
  • 每文件系统最大独立 fileset 数量为 3000, 每文件系统最大独立和非独立 fileset 数量为 10000
    • 独立 fileset 使用独立 inode 空间 (mmcrfileset --inode-space new)
    • 非独立 fileset 使用共享 inode 空间 (缺省)
# 创建 fileset
mmcrfileset fs0 fset1
# 链接 fileset 到文件系统上位置
mmlinkfileset fs0 fset1 -J /share/fset1
# 查看 fileset 信息
mmlsfileset fs0

quota 管理#

quota 只能在拥有集群（owning cluster）上设置：

# 设置大小软限制 95G，硬限制 100G；文件软限制 95K，硬限制 100K
mmsetquota fs0:fset1 --block 95G:100G --files 95K:100K
# 查看 quota 信息
mmlsquota -j fset1 fs0
mmreqquota -a

对 root 用户施加 fileset quota 限制，只需在访问集群（accessing cluster）上执行：

mmchconfig enforceFilesetQuotaOnRoot=yes -i

enforceFilesetQuotaOnRoot 说明

如果在开启 enforceFilesetQuotaOnRoot 之前已经写入过数据，需要在拥有集群上执行 mmcheckquota <fs> 重新核算配额用量，否则已有用量统计不准，可能出现无法写入的情况。

QoS 管理#

Scale 不支持对 Metadata IOPS 进行 QoS 限制, 在多租户/多用户使用场景存在 Metadata 性能竞争

# 启用 QoS 并查看状态
mmqos filesystem enable fs0
mmqos filesystem status fs0

# 创建 QoS 类
# 其中 root fileset 也可设置 QoS，但其仅仅限制 root fileset
mmqos class create fs0 --class fs0-fset1 --fileset fset1
mmqos class list fs0

# 创建 QoS 限制
mmqos throttle create fs0 --pool all --class fs0-fset1 --maxiops 1000 --maxmbs 100
mmqos throttle list fs0
