GPFS 集群扩缩容#

集群扩容先决条件#

请参考 GPFS 存储集群部署 中创建存储集群的先决条件说明。

横向扩容存储集群#

通过增加新的节点实现集群的横向扩容。

使用安装工具包扩容新节点#

# 确定安装节点

安装节点就是最初执行spectrumscale命令的节点。

# 切换到ansible-toolkit目录
cd /usr/lpp/mmfs/5.x.y.z/ansible-toolkit/

# 在集群定义文件中添加节点
./spectrumscale node add sn005 -so
./spectrumscale node add sn006 -so 
./spectrumscale node add sn007 -so 
./spectrumscale node add sn008 -so 


# 执行安装工具包安装
./spectrumscale install --skip no-ece-check


# 拷贝描述文件到新节点
pdcp -w sn005,sn006,sn007,sn008 /usr/lpp/mmfs/data/gems/*.edf /usr/lpp/mmfs/data/gems/

扩容文件系统#

以下扩容方法根据实际应用场景二选一。

扩容已有RG#

# 配置节点.这会触发daemon滚动更新
mmvdisk server configure -N sn005

# 节点加入到RG1
# 该步骤会自动执行如下操作：
# 1. 检查节点资源是否符合要求
# 2. sn005节点加入到NC1中
# 3. 获取当前RG1中pdisk 信息
# 4. 分析所有节点的磁盘拓扑信息
# 5. 认证RG1中的DA1
# 6. 更新RG1中的服务器列表和pdisk列表
# 7. 格式化sn005节点上的磁盘
# 8. 把sn005的磁盘加入到DA1中
# 9. 节点sn005加入到恢复组RG1
# 10. DA1中磁盘均衡
# 11. 新节点日志组和vdiskset自动创建。
mmvdisk rg add --rg RG1 -N sn005

# 以上命令执行成功后会自动进入数据的重新均衡状态。
# 确认数据均衡任务执行状态，也就是RG的remarks值为rebalance in progress状态。
# 新节点加入后文件系统大小不会变化，当数据均衡做完以后文件系统扩容成功，大小为目标大小。
mmvdisk rg list --rg RG1

# 上述步骤做完以后如果mmhealth cluster show node 显示ill_unbalanced_fs 警告需要对文件系统进行重新均衡
mmrestripefs fs1 -b

创建新的RG#

# 创建节点类
mmvdisk nc create --nc NC2 -N sn005,sn006,sn007,sn008
mmvdisk nc list --nc all
# 这会触发 daemon 滚动重启
mmvdisk server configure --nc NC2 --recycle one --pagepool 70%
mmvdisk server list --nc NC2 --disk-topology

# 创建恢复组, nvme 插槽映射必须完成
mmvdisk rg create --rg RG2 --nc NC2
mmvdisk rg list --da

# 创建元数据和数据分离的 vdisk set。--set-size参数可以指定百分比（如：90%）也可以指定大小（如：50T）.
mmvdisk vs define --vs fs1meta2 --rg RG2 --code 4WayReplication --bs 512K --da DA1 --nsd-usage metadataonly --sp system --set-size 5%
mmvdisk vs define --vs fs1vs2 --rg RG2 --code 8+3P --bs 4M --da DA1 --nsd-usage dataonly --sp data --set-size 90%
mmvdisk vs create --vs fs1meta2
mmvdisk vs create --vs fs1vs2

# 创建元数据和数据混合的 vdisk set。 --set-size参数可以指定百分比（如：90%）也可以指定大小（如：50T）.
mmvdisk vs define --vs fs2vs4 --rg RG2 --code 8+3P --bs 4M --da DA1 --nsd-usage dataAndMetadata  --sp system --set-size 50T
mmvdisk vs define --vs fs2vs5 --rg RG2 --code 8+3P --bs 4M --da DA1 --nsd-usage dataAndMetadata  --sp system --set-size 50T
mmvdisk vs define --vs fs2vs6 --rg RG2 --code 8+3P --bs 4M --da DA1 --nsd-usage dataAndMetadata  --sp system --set-size 50T
mmvdisk vs create --vs fs2vs4
mmvdisk vs create --vs fs2vs5
mmvdisk vs create --vs fs2vs6
mmvdisk vs list --vs all

# 扩容文件系统 fs1
mmvdisk fs add --fs fs1 --vs fs1meta2,fs1vs2 

# 平衡文件系统。
mmrestripefs fs1 -b

# 扩容文件系统 fs2
mmvdisk fs add --fs fs2 --vs fs2vs4 

# 平衡文件系统。
mmrestripefs fs2 -b

横向缩容存储集群#

从现有存储集群移除一部分节点以实现缩容存储集群。

# 把一个RG内的节点置为维护状态
# mmvdisk rg change --rg RG1 --suspend -N sn005

# 从文件系统中删除节点
mmvdisk filesystem delete --file-system fs1 --vdisk-set fs1meta,fs1vs1 --recovery-group RG1 -N sn005

# 从RG中删除节点
mmvdisk rg delete --rg RG1 -N sn005

# 停掉sn005上面的gpfs服务
mmshutdown -N sn005

# 从GPFS中删除节点sn005
mmdelnode -N sn005

# 重新均衡文件系统
mmrestripefs fs1 -b
