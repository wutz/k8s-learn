GPFS 性能调优#

优化吞吐性能

# 表示 GPFS 在单节点允许体检的读写数据流最大速率, 缺省值为 2048
# GPFS 利用此参数来计算应为顺序文件访问（Sequential Access）分配多少个预读（prefetch）或后台写入（write-behind）线程
#
# 设置每节点最大网络吞吐量的 2 倍, 且最大值为 100000
# 例如配置 4x 200Gb 网络，则为 4*200*1000/8*2=200000MB/s, 由于超过最大值限制则取最大值
mmchconfig maxMBpS=100000
# 查看生效值
mmdiag --config | grep maxMBpS

# workerThreads 是一个全局性的性能调优参数，用于控制节点上用于处理并发文件系统请求的工作线程池大小
# 处理来自应用程序的并发读写、元数据操作（如创建、删除文件）以及内部维护任务
# 存储集群
mmchconfig workerThreads=3072
# 客户端集群
mmchconfig workerThreads=1024

优化元数据 (元数据 Read & Stat 提升巨大)

# maxFilesToCache 指定每个节点可以在内存中缓存的完整 inode（索引节点）的最大数量
# 每个缓存 inode 大约占用 3K - 10K 内存
# 存储集群
mmchconfig maxFilesToCache=3M
# 客户端集群
mmchconfig maxFilesToCache=1M

# maxStatCache 指定在内存中缓存的文件属性（stat 信息）的最大数量
# 它只记录文件的基本属性（如 ls -l 显示的信息），不足以直接打开或读写文件，但足以响应属性查询
# 每个缓存占用 400 - 500 字节内存
# 存储集群
mmchconfig maxStatCache=4M
# 客户端集群
mmchconfig maxStatCache=1M

修改配置参数需要重启 daemon

mmshutdown -a && mmstartup -a
mmgetstate -a
