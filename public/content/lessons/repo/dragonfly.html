Dragonfly#

Dragonfly 提供基于 P2P 的镜像与文件分发服务。

本方案是备选的镜像 P2P 服务。缺省方案是在 base 阶段部署的 Spegel，两者部署其一即可；如果集群已部署 Spegel，改用 Dragonfly 前先卸载 Spegel。

相比 Spegel，Dragonfly 额外支持预热 (preheat, 首次拉取也能加速)、分发模型权重等非镜像文件、containerd 之外的运行时，以及跨集群的 P2P 调度与流量统计；代价是组件更多 (manager / scheduler / seed client / client + MySQL + Redis)、资源开销更高。选型对比见 仓库服务。

配置#

配置详情参考 values.yml。

创建 seed client secret (如果使用)#

kubectl create secret generic seed-client-secret \
  --from-file=cr.example.com.pem=./cr.example.com.pem \
  -n dragonfly-system

创建 client secret （如果使用）#

kubectl create secret generic client-secret \
  --from-file=cr.example.com.pem=./cr.example.com.pem \
  -n dragonfly-system

部署#

helmwave up --build

访问 dragonfly web 控制台#

kubectl port-forward svc/dragonfly-manager -n dragonfly-system 8080:8080
  • 浏览器访问： http://localhost:8080

默认： root/dragonfly
