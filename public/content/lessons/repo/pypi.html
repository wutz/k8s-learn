部署 PyPI Mirror#

基于 devpi 提供私有仓库和按需缓存 Mirror 功能。

部署#

  1. 修改 prod/deployment.yaml 中的 DEVPI_PASSWORD
  2. 修改 prod/deployment.yaml 中的 http_proxy 和 https_proxy
  3. 修改 prod/ingress.yaml 中的 pypi.example.com
  4. 修改 prod/pvc.yaml 中的 storage 大小 (只存储被拉取过的 PyPI 数据，全量在 20Ti 左右，按需调整)
kubectl apply -k prod/

配置#

部署完成后，需要修改 Mirror 服务器以加快拉取速度。

pip install devpi-client
# 使用实际域名
devpi use https://pypi.example.com
devpi login root --password $DEVPI_PASSWORD
devpi index root/pypi volatile=True
devpi index --delete root/pypi
# https://mirrors.163.com/pypi/simple/ 和 https://pypi.tuna.tsinghua.edu.cn/simple 都有兼容问题，建议上游使用 pypi.org (依赖代理)
devpi index -c root/pypi type=mirror mirror_url=https://pypi.org/simple/
devpi index root/pypi volatile=False

使用#

# 使用实际域名
pip config set global.index-url https://pypi.example.com/root/pypi/+simple/
